# Moja Vedomostná Karta

Vědomostní kvíz vytvořený v Pythonu s grafickým rozhraním PyQt5.

## Funkce
- Vědomostní otázky
- Obtížnější úroveň
- Grafické rozhraní PyQt5
- Zvuková zpětná vazba

## Instalace
```bash
python -m venv .venv
```

Linux (fish):
```fish
source .venv/bin/activate.fish
```

Instalace závislostí:
```bash
pip install -r requirements.txt
```

## Spuštění
```bash
python moja_vedomostna_karta.py
```
